# idea-shelf (한국어판)

작업 도중 떠오른 곁가지 아이디어를 Claude의 흐름을 끊지 않고 선반에 올려 두었다가, 나중에 클릭 한 번으로 Claude에게 보내요. Claude도 작업하다 발견한 곁가지를 직접 선반에 올리고, 방금 한 작업과 맞는 아이디어가 있으면 알려 줘요. 프로젝트 폴더마다 선반이 따로 있고, 세션이 끝나도 남아 있어요.

한국어판 제작: [robinade](https://github.com/robinade) · [mod 모음과 필요 조건](../README.md)

## 설치

터미널에서 Claude Code를 열고, 입력창에:

```
/plugin install idea-shelf --marketplace robinade/claude-mods-ko
```

처음 한 번은 `Add marketplace?`를 물어요. `y`를 누르고, 설치 범위는 맨 위의 `user`에서 Enter를 눌러요. 그 세션에서 바로 켜지고, 이후 여는 모든 세션에서도 켜져요.

- **업데이트**: `claude plugin marketplace update claude-mods-ko`를 실행한 다음 `claude plugin update idea-shelf@claude-mods-ko`를 실행하고, Claude Code를 다시 시작해요.
- **필요 조건**(Claude Code 2.1.295 이상, 모델 호출 비용, `CLAUDE_CODE_ATTRIBUTION_HEADER`)과 6종을 한 번에 설치하는 방법은 [mod 모음 README](../README.md)에 있어요.
- **설치 없이 한 세션만 써 보기**: 레포를 받은 뒤(`git clone https://github.com/robinade/claude-mods-ko`) `claude --plugin-dir claude-mods-ko/idea-shelf`로 실행해요.

## 사용법

- `/idea <내용>`: 아이디어를 선반에 올려요. 한국어 그대로 저장돼요.
- `/idea` (내용 없이): 선반을 열어요.
- 선반에서: `+` 칸에 입력하면 추가돼요. `보내기`는 아이디어를 Claude에게 넘겨요(Claude가 쉬는 차례에 시작해요). `✕`는 지워요. 아이디어마다 누가 올렸는지 `나` 또는 `Claude`로 표시돼요. `Esc`로 프롬프트로 돌아가요.

## Claude가 직접 올리는 아이디어

이 모드는 Claude에게 `shelve_idea` 도구를 주고, 작업 도중 발견한 범위 밖의 곁가지(리팩터링, 빠진 테스트, 정리 등)는 손대지 말고 선반에 올리라고 시스템 프롬프트로 알려 줘요. Claude가 올리는 아이디어는 한국어 한 줄로 쓰이고, 파일·폴더 이름은 원래 표기 그대로 들어가요. 올라오면 짧은 알림이 뜨고, 선반에서 `Claude`로 표시돼요. 사용자가 보내기 전에는 아무것도 실행되지 않아요.

## 관련 아이디어 알림

한 턴이 끝나면 선반의 아이디어 키워드를 그 턴의 주제(내 프롬프트의 단어, Claude가 고치거나 만든 파일 이름과 폴더)와 비교해요. 맞는 게 있으면 프롬프트 위에 `💡 방금 한 작업과 맞는 아이디어 2개: …` 줄이 뜨고:

- `보내기`: 그 아이디어들을 한 번에 Claude에게 넘기고 선반에서 빼요.
- `닫기`: 줄을 숨겨요. 이번 세션에서는 그 아이디어들을 다시 알리지 않아요.

턴마다 최대 한 번이고, 다음 턴이 시작되면 사라져요. 같은 턴에 Claude가 올린 아이디어는 바로 다시 알리지 않아요.

### 한국어 매칭 방식

비교는 모델 호출 없이 단어 겹침으로 해서 빠르고 비용이 들지 않아요. 한국어는 다음처럼 처리해요.

- 조사와 흔한 어미를 떼고 비교해요: `결제에서`, `결제가`, `결제를` 은 모두 `결제`로 봐요. `캐싱하기로` 는 `캐싱`.
- 어디에나 붙는 말(이거, 좀, 해줘, 코드, 파일, 수정, 추가, 개선, 작업, 기능 등)은 빼요. 이런 말만 겹치면 알리지 않아요.
- 띄어 쓰지 않은 복합어는 세 글자 이상 어간이 들어 있으면 맞는 걸로 봐요(`로그인화면` ↔ `로그인`). 두 글자 어간은 정확히 같아야 해요(`로그` 와 `로그인` 은 다름).
- 영어 단어와 파일 이름 비교는 원래 방식 그대로예요.

사전 없이 하는 단순 비교라 가끔 놓치거나 엉뚱하게 맞을 수 있어요.

## 참고

- 선반 안 `+` 칸이나 버튼은 한/영 상태와 상관없이 쓸 수 있어요. 단축키가 있는 버튼은 없어요.
- 저장 위치: Claude Code 설정 폴더의 이 모드 전용 저장소(`ideas:<작업 폴더>` 키). 원본 영어판과 같은 키라 예전에 올린 아이디어도 그대로 보여요.
