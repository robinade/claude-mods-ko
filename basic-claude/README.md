# plain-talk (한국어판)

Claude가 쉽고, 빠짐없고, 그것만 읽어도 이해되는 한국어로 답하게 해요. 세션이 지금 뭘 하는지 보여주는 상태 줄을 붙이고, 세션이 끝나서 확인이 필요하면 소리로 알려줘요(소리 파일은 직접 넣어야 해요. [알림 소리](#알림-소리) 참고).

한국어판 제작: [robinade](https://github.com/robinade) · [mod 모음과 필요 조건](../README.md)

원본 plain-talk을 한국어 사용자에 맞게 고친 버전이에요. 저장 데이터(수준, 아는 용어 목록)는 원본과 그대로 호환돼요.

## 설치

터미널에서 Claude Code를 열고, 입력창에:

```
/plugin install plain-talk --marketplace robinade/claude-mods-ko
```

처음 한 번은 `Add marketplace?`를 물어요. `y`를 누르고, 설치 범위는 맨 위의 `user`에서 Enter를 눌러요. 그 세션에서 바로 켜지고, 이후 여는 모든 세션에서도 켜져요.

- **업데이트**: `claude plugin marketplace update claude-mods-ko`를 실행한 다음 `claude plugin update plain-talk@claude-mods-ko`를 실행하고, Claude Code를 다시 시작해요.
- **필요 조건**(Claude Code 2.1.295 이상, 모델 호출 비용, `CLAUDE_CODE_ATTRIBUTION_HEADER`)과 6종을 한 번에 설치하는 방법은 [mod 모음 README](../README.md)에 있어요.
- **설치 없이 한 세션만 써 보기**: 레포를 받은 뒤(`git clone https://github.com/robinade/claude-mods-ko`) `claude --plugin-dir claude-mods-ko/basic-claude`로 실행해요.

## 사용법

명령 이름은 `/plain` 그대로예요. 뒤에 붙이는 말은 한국어와 영어 모두 돼요.

| 명령 | 하는 일 |
|---|---|
| `/plain` | 지금 수준과 아는 용어 개수 보기 |
| `/plain 초보` (`beginner`) | 더 쉽게, 더 많이 풀어서 설명해요 (기본값) |
| `/plain 전문가` (`expert`) | 기술 용어는 그대로 쓰고 덜 풀어요 |
| `/plain 끄기` (`off`) | 쉬운 말 규칙을 꺼요 |
| `/plain know <용어>` (`알아 <용어>`) | 이미 아는 용어로 등록해요. Claude가 더는 풀어 설명하지 않아요. 쉼표로 여러 개 (`/plain know api, 풀 리퀘스트`) |
| `/plain know` (`용어`) | 아는 용어 목록 보기 |
| `/plain forget` (`잊기`) | 아는 용어 목록 지우기 |

수준과 용어 목록은 저장돼서 다음 세션에도 이어져요. 짧은 용어(세 단어까지)만 저장해요. `"풀 리퀘스트: 코드 변경 요청"`은 `풀 리퀘스트`로, `"API(프로그램끼리 대화하는 통로)"`는 `api`로, `"커밋을"`은 `커밋`으로 정리해서 저장하고, 긴 문장은 버려요.

전문 용어, 더 자세한 설명, 정확한 원문을 직접 요청하면 수준과 상관없이 그대로 줘요.

## Claude가 따르는 규칙

- 답변은 모두 한국어로 써요. 다른 언어를 직접 요청할 때만 예외예요.
- API, PR, 커밋, 배포처럼 개발 현장에서 흔한 영어 용어도 처음 나올 때 한 번 쉬운 말로 풀어줘요 (`초보` 수준). 아는 용어로 등록한 건 풀지 않아요.
- 작업을 한 턴은 마지막 답변을 **완료:** / **남은 일:** / **다음 할 일:** 세 부분으로 끝내요.
- 사용자 본인 지시(CLAUDE.md, 메모리, 대화 중 요청)가 언제나 이 규칙보다 먼저예요.

규칙 문장은 `hooks/rules.ts`에 한국어로 있어요. 마음대로 고쳐도 돼요.

## 답변 검사

답변이 끝날 때마다 작은 모델(haiku)이 한 번 검사해요. 검사는 너그러워요. 이번 턴의 요청과 아는 용어 목록을 보고, 정말 헷갈릴 때만 실패로 쳐요:

1. 모르는 용어를 요청하지도 않았는데 설명 없이 썼을 때 (한국어 문장에 영어 용어가 섞인 것 자체는 괜찮아요)
2. 요청한 답을 실제로 주지 않았을 때
3. 다른 언어를 요청하지 않았는데 답변이 한국어가 아닐 때

결과는 프롬프트 위 띠(밴드)에 상태 줄과 함께 보여요:

- `✓ 쉬워요`: 괜찮은 답변이에요. 사소한 스타일 지적은 `✓ 쉬워요 · 참고: …`로 보이지만 실패로 치지 않아요.
- `✗ 문제 2개: …`: 헷갈릴 만한 답변이에요. 문제가 적혀 있어요.

실패하면 plain-talk이 Claude에게 한 번 다시 써 달라고 해요 (밴드에 `· 다시 쓰는 중`이 붙어요). 다시 쓴 답변은 또 다시 쓰지 않고, 수준이 `끄기`일 때는 검사도 다시 쓰기도 안 해요. 검사 자체가 실패하면 밴드에는 상태 줄만 보이고, 세션마다 한 번만 대화에 이유를 적어요. `CLAUDE_CODE_ATTRIBUTION_HEADER`가 함께 보이면 `~/.claude/settings.json`의 `env`에서 `CLAUDE_CODE_ATTRIBUTION_HEADER: "0"`을 지우고 새 세션을 여세요. 이 값이 `0`이면 모드가 따로 부르는 모델 호출이 매번 429로 막혀요. 자세한 내용은 [prompt-enhancer README](../prompt-enhancer/README.md#429-오류가-날-때)에 있어요.

`초보` 수준에서는 Claude가 그 답변에서 풀어 준 용어가 밴드의 **이건 알아요:** 옆에 버튼으로 떠요. 누르면 아는 용어로 등록돼요. 누르거나 `/plain know`를 쓰지 않으면 아무것도 등록되지 않아요. 밴드 버튼은 `ctrl+x tab`으로 밴드로 옮겨간 뒤 `Tab`과 `Enter`로 누르거나, 마우스로 클릭하세요.

## 알림 소리

세션이 끝나서 확인이 필요하면 mod 폴더의 `sounds/done.aiff`를 재생해요. macOS에서만 소리가 나요(`afplay` 사용).

- 이 소리 파일은 저작권 때문에 레포에 넣지 않았어요. 파일이 없으면 소리만 안 나고, 상태 줄과 밴드는 그대로 동작해요.
- 소리를 쓰려면 설치된 plain-talk 폴더(보통 `~/.claude/plugins/` 아래)의 `sounds/done.aiff` 자리에 원하는 소리 파일을 넣으세요. 업데이트하면 다시 넣어야 할 수 있어요.

## 비용

검사는 답변마다 haiku를 한 번 부르고, 실패한 답변은 Claude가 한 번 더 써요. 그만큼 시간과 사용량이 늘어요. 아끼고 싶으면 `/plain 전문가`(덜 실패해요)나 `/plain 끄기`를 쓰세요.
